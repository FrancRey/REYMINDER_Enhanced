Privacy Policy

Last updated: October 2026

Information we collect

This educational prototype stores the name and email address you submit when creating an account, a password hash, and reminders you create (including titles, notes, categories, dates, and completion status).

How information is used

Information is used to authenticate your account and display and manage your reminders. Passwords are stored as hashes rather than plain text. This local prototype does not send reminders or account information to an email service.

Storage and sharing

For the local prototype, data is stored in a SQLite database file on the computer running the app. It is not designed for sensitive information. Do not enter confidential, medical, financial, or other sensitive personal data.

Retention and deletion

In this prototype, reminders can be deleted through the dashboard. Account deletion is not yet available in the interface; for a test installation, stop the application and remove the local database file to clear its stored data.

Security and limitations

This is a student learning project, not a production service. Security measures are limited, and no website can guarantee absolute security. Do not deploy this version publicly with real personal data.

Contact

For a class demonstration, contact the student developer through the contact details provided by the course instructor. Replace this text with an appropriate contact method before public deployment.
